# Cambodia by Motorbike

A simple, responsive trip-guide template for GitHub Pages. Plain HTML and CSS; no build tools or dependencies.

## Local development

From this checkout, run:

```sh
python3 -m http.server 8000
```

Edit `index.html` for content and `styles.css` for appearance.

## GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then **Save**.

The expected site address is https://williamlow.github.io/cambodia-trip/ . GitHub may take a few minutes to publish. Subsequent pushes to `main` publish automatically.

The itinerary is placeholder content, not a confirmed route.
